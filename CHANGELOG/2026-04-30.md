# 2026-04-30

## Added
- Integrasi Cloudflare Pages Functions dan D1 untuk backend BidanKita.
- Database schema untuk akun user, sesi login, profil bidan, thread chat, dan pesan chat.
- Database schema `appointments` untuk janji kunjungan customer dan bidan.
- Login dan registrasi akun customer dengan session token.
- Admin panel untuk mengelola satu bidan utama dan daftar customer.
- CRUD customer untuk admin, termasuk ganti password dan hapus akun.
- Chat customer-bidan yang tersimpan di D1 dengan inbox untuk admin/bidan.
- Tampilan chat dengan nama pengirim, role pengirim, avatar, dan auto-refresh berkala.
- Upload foto profil untuk customer dan bidan melalui halaman Profil.
- Endpoint appointment untuk `GET`, `POST`, `PATCH`/`PUT`, dan `DELETE`.
- Halaman `Kunjungan` berbasis database untuk customer, bidan, dan admin.
- Admin/bidan dapat melihat nama customer pada janji kunjungan.
- Admin/bidan dapat membuat, mengedit, menghapus, dan mengubah status janji customer.
- Tombol cepat `Sudah ditangani` untuk admin/bidan pada janji yang masih `Akan datang`.
- Dokumentasi fitur janji kunjungan di `docs/appointment-admin.md`.
- Fallback API production saat app dijalankan dari localhost.

## Changed

- Sapaan beranda mengikuti nama akun yang sedang login.
- Daftar bidan dibatasi ke satu bidan utama.
- Profil menampilkan avatar jika sudah diunggah.
- Status internal `Selesai` ditampilkan ke user sebagai `Sudah ditangani`.
- README diperbarui dengan detail backend Cloudflare, D1, akun demo, deploy, dan checklist pengujian.
- Lint config mengabaikan artifact Wrangler sementara.
